# 서버 자동 배포 설정 (처음 한 번)

설정이 끝나면 Code.gs 가 바뀌어 올라갈 때 GitHub 이 **테스트 시트 서버**에 자동으로 붙여 넣고 ‘새 버전’으로 배포합니다(주소 그대로).
본서버는 "본서버에 올려" 때만 배포합니다(Actions › server-deploy › Run workflow › prod).

## 1. Apps Script API 켜기 (휴대폰도 가능)
https://script.google.com/home/usersettings → ‘Google Apps Script API’ **사용**

## 2. 로그인 정보 만들기 (컴퓨터, 한 번)
1. https://nodejs.org 에서 LTS 설치
2. 터미널(맥: 터미널 / 윈도: PowerShell)에서
   ```
   npx @google/clasp@2.4.2 login
   ```
   → 브라우저가 열리면 시트 주인 구글 계정으로 로그인 · 허용
3. 생긴 파일 내용을 복사
   - 맥: `cat ~/.clasprc.json | pbcopy`
   - 윈도: `Get-Content $HOME\.clasprc.json | Set-Clipboard`
   - **이 내용은 비밀번호와 같습니다. 채팅·메모에 붙이지 말고 아래 GitHub 칸에만 붙이세요.**

## 3. 스크립트 ID · 배포 ID 찾기 (시트마다)
- 스크립트 ID: 시트 › 확장 프로그램 › Apps Script › 왼쪽 ⚙ 프로젝트 설정 › ‘스크립트 ID’
- 배포 ID: 배포 › 배포 관리 › 지금 웹 앱 배포를 누르면 보이는 ‘배포 ID’ (AKfy… 로 시작)

## 4. GitHub 비밀값 넣기
https://github.com/yeemee4/farm-app-j039ry/settings/secrets/actions → **New repository secret** 를 다섯 번

| 이름 | 값 |
|---|---|
| CLASPRC | 2번에서 복사한 내용 전체 |
| GAS_SCRIPT_TEST | 테스트 시트 스크립트 ID |
| GAS_DEPLOY_TEST | 테스트 시트 배포 ID |
| GAS_SCRIPT_PROD | 본 시트 스크립트 ID |
| GAS_DEPLOY_PROD | 본 시트 배포 ID |

## 5. 시험
https://github.com/yeemee4/farm-app-j039ry/actions/workflows/server-deploy.yml → **Run workflow** → target `test` → 초록 체크면 끝.

## 끊고 싶을 때
https://myaccount.google.com/permissions 에서 ‘clasp’ 접근 삭제 → 자동 배포가 즉시 멈춥니다.
